# CompTIA Troubleshooting Methodology (6 steps) — MEMORIZE IN ORDER

1. **Identify the problem**
   - Gather info from the user, identify user changes, and, if applicable, perform backups before making changes.
   - Inquire regarding environmental or infrastructure changes.
2. **Establish a theory of probable cause** (question the obvious)
   - If necessary, conduct external or internal research based on symptoms.
3. **Test the theory to determine the cause**
   - If confirmed → determine next steps to resolve.
   - If not confirmed → re-establish a new theory or **escalate**.
4. **Establish a plan of action** to resolve the problem and implement the solution
   - Refer to vendor instructions for guidance.
5. **Verify full system functionality** and, if applicable, implement preventive measures.
6. **Document** findings, actions, and outcomes.

Mnemonic: **"I Eat Tacos Every Very Day"** — Identify, Establish theory, Test, Establish plan, Verify, Document.

Exam tip: if a question asks "what should the technician do NEXT?", find which step they're on and pick the next one.
