# Core 1 · Domain 1 — Mobile Devices (13%)

## Laptop hardware
- Replaceable parts: battery, keyboard, RAM (SODIMM), storage (2.5" SSD/HDD, M.2), wireless card, screen/digitizer, biometrics, NFC.
- Use manufacturer service manual; ESD strap; track screws on a magnetic mat.

## Display components
- **LCD** (IPS = best viewing angles/color, TN = fast/cheap, VA = good contrast), **OLED** (no backlight, true blacks), mini-LED.
- Wi-Fi antennas usually run around the display bezel.
- Digitizer = touch layer; inverter only on old CCFL backlights.
- Webcam + microphone typically in the top bezel.

## Accessories & connectivity
- Wired: USB-C/Thunderbolt, Lightning, serial (legacy).
- Wireless: **Bluetooth** (pair → PIN → test), **NFC** (tap to pay), hotspot, IR.
- Docking station vs. port replicator; stylus, headsets, speakers, webcams, trackpads.

## Mobile networking & management
- Cellular: 4G/LTE, 5G; hotspot/tethering; SIM/eSIM.
- GPS / location services.
- **MDM** (Mobile Device Management): enforce policies, remote wipe, app control, corporate email config.
- Synchronization: calendar, contacts, email, photos — cloud (iCloud, Google, Microsoft 365).
- Two-factor / authenticator apps.
